`ViewWorkflowCoordinator` and `WindowsViewProvider` manage storage lifetimes. `SourceViewDeltaStore` separates per-generation source journals from the common cache journal; `CacheSnapshotTree` reads the fixed cache basis. `ImmutableCandidate` is an immutable range candidate depending on a snapshot. `GitSourceResult`'s independent result does not indicate compilation, Play/Test/build success.

Request errors are `ViewRequestInvalid`/`ViewContractUnsupported`; ownership/resource errors are `ViewOwnerMismatch`/`ViewResourcesBusy`/`ViewResourcesUnknown`; receipt/state errors are `ViewReceiptInvalid`/`ViewReceiptMismatch`/`ViewStateCorrupt`. `ViewStateRecoveryRequired` requires explicit retry with the same inputs. `ViewSourceChanged`/`ViewResultInvalid` preserve original files/results; open source generations/cache block reclamation with `ViewDependencyActive` or workspace `SnapshotInUse`. `WorkspaceFailurePolicy` owns response preservation/retry classification.

Common-ledger `validation-workflows`, provider `validation-product`, mount `validation-mounts`, and Git-result `refs/splinter/validation-results` are currently used storage identities. Their query paths, task IDs, and lock keys remain to connect workspace/restricted-service dependency queries and protect already-preserved independent results. The current parser preserves and rejects unsupported fields/requests/corrupt state. No conversion, additional reader, or automatic-recovery fallback is provided.
