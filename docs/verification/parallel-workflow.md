## 현재 후보의 소스 확인 비용

큰 에셋의 최초 복사를 하지 않는 것과 에셋을 읽지 않는 것은 다르다. 현재 `GitWorkspaceProvider.InspectAsync`는 fingerprint를 계산할 때 관리 대상 캐시를 제외한 모든 추적·미추적 소스 파일을 읽어 SHA-256을 계산한다. 스크립트 한 개를 수정해도 대표 에셋 약 2.6GiB가 읽기 대상이다. 이 읽기는 hydration이나 payload 복사가 아니지만 시간·CPU·논리 I/O를 사용한다.
