# Security boundary verification

[한국어](../ko/verification/security-boundaries.md)

SB-02 records a historical authentication candidate for the removed external patch feature. The current product requires no external MCP token, fixed version, or candidate preparation/connection and provides no patch production/operation. Existing candidates, installations, servers, and evidence are preserved. Current responsibilities follow the [external-tool boundary](../unity-mcp-response-recovery.md).

Selected scope comprises Plastic/MCP access by another local Windows account, write ACLs on service child files, global reclaim-lock preemption, and incomplete IPC reception. Original/peer, snapshots, service ledger, and existing external candidates are preserved. No installation/grant change, VSS reclaim, Unity A/B, new malicious project, or full attack matrix is executed. Raw verification is at `artifacts/security-fixes/`.

Required `pwsh ./scripts/build.ps1` passed locked restore and Release build with 0 warnings/errors, **1,036 total: 1,026 Passed / 0 Failed / 10 conditional Skipped**. Skips are tests excluded at the time and evidence/child entrypoints requiring separate execution input. Final raw evidence is `artifacts/security-fixes/required-build-complete.log` and `required-build-complete.trx`, executed as an ordinary user. Existing named-pipe tests also reject connections under restricted tokens, so those failures are not counted as product failures. An intermediate full execution discovered a missing capabilities schema and a new pipe test waiting on writes before reading; it was stopped and its logs preserved. The corrected 4 pipe tests were checked first, then final full regression completed.

Requests, state, and workspace v2 retain existing contracts; the capabilities Plastic-reader description is also added to the response schema. Dependencies/lockfiles unchanged; the bridge is a fixed-version internal adapter, not claimed as a stable public SDK for the vendor library. The helper retains 4MiB decoded scratch and frames up to 64KiB; vendor packet/native allocation, external cache/communication, and total RAM peak remain separately unmeasured.

Current security-fix code is distinguished from the installed/running environment. Applying service changes to execution environments follows an explicit Update with a new service package and separate qualification. Historical external MCP candidate connection is not a current product installation requirement. v1 candidates, original manifest/lock, shared servers, and other Editors are not automatically replaced. Historical PPB/MR actual Unity qualification remains evidence for its reader/candidate at the time, not inherited as Passed for the new candidate.
